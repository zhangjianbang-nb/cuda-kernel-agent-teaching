一 · 从积分到乘积：平均功率近似的误差结构

能耗定义式 $$E=\int_0^T P(t)\,dt$$ 在工程上几乎从不按原样使用，因为 $$P(t)$$ 是微秒级抖动的随机过程，逐点采样需要板载功率计与高频采样链路，采样本身引入的观测开销会污染被测 kernel 的时延。实际落地的是右端的乘积形式 $$E\approx\bar P\cdot T$$，其中 $$\bar P$$ 是窗口内的平均功率。这一步替换不是无害的代数化简，它把积分误差转移成了两个可分离的误差源。

把窗口切成 $$n$$ 段，段长 $$\Delta t$$，则矩形近似的截断误差满足 $$\left|E-\bar P T\right|\le \tfrac{1}{2}T\cdot \max_t\left|P'(t)\right|\cdot \Delta t$$。误差正比于功率对时间的导数上界与采样间隔之积。这解释了为什么短 kernel 的能耗测量比长 kernel 更不可信：$$T$$ 小的时候，启动瞬态与收尾瞬态在总积分中占比上升，$$P'(t)$$ 的峰值恰好落在这些瞬态里，而 $$\bar P$$ 把它们抹平成一个常数。一个具体例子：某 kernel 稳态功率 180 W、持续 40 μs，但启动阶段有 15 μs 从 40 W 爬升到 180 W 的斜坡。用全程平均功率乘总时延，会把斜坡段的低功率过度计入稳态段，得到偏高的能耗估计；若把窗口起点放在斜坡之后，又漏掉了真实存在的启动能量。两种切法给出的 $$E$$ 差异可达百分之十几，而这个差异与 kernel 本身无关，只与窗口定义有关。

因此本部分后续所有推导都显式携带一个前提：$$\bar P$$ 的语义由窗口定义固定，且窗口必须与被比较的 kernel 共享同一套边界规则（是否含 launch、是否含尾部同步、是否扣除空闲基线）。代价是测量时延：高频功率采样的存储带宽与后处理开销随采样率线性增长，把采样率提高一个量级，单次实验的数据落盘与聚合时间也近似提高一个量级，这在多轮搜索里直接换算成 token 预算与墙钟预算的挤压。

二 · 功率分解：把 $$\bar P$$ 拆成可归因的项

要让帕累托前沿上的点可解释，必须把 $$\bar P$$ 拆成与 kernel 属性挂钩的分项。一个够用的分解是 $$\bar P=\bar P_{\text{static}}+\bar P_{\text{dyn}}+\bar P_{\text{mem}}$$，分别对应静态漏电与时钟树、计算单元翻转、访存子系统活动。动态项可写成 $$\bar P_{\text{dyn}}\approx \alpha C V^2 f\cdot u$$，其中 $$\alpha$$ 是活动因子、$$C$$ 是等效电容、$$V$$ 是电压、$$f$$ 是频率、$$u$$ 是占用率。这个式子的关键含义是：$$u$$ 进入的是功率的乘性因子，而它同时进入时延的分母——占用率提高既缩短 $$T$$ 又抬高 $$\bar P$$，两者对 $$E$$ 的作用方向相反，这正是「提速但能耗更高」得以存在的代数根源。若 $$T\propto 1/u$$ 严格成立，则 $$E\approx \bar P T$$ 中的 $$u$$ 会完全抵消；真实情况是 $$T$$ 随 $$u$$ 的下降比线性更慢（存在固定开销与尾部串行段），于是乘积随 $$u$$ 单调上升，高占用率反而更费电。

访存项 $$\bar P_{\text{mem}}$$ 不能简单并入动态项，因为它的代价结构不同：一次全局访存的能量与传输字节数近似成正比，而与计算量无关。把 kernel 的算术强度记为 $$I=\text{FLOP}/\text{Byte}$$，则在 roofline 意义下（可达上界的讨论见 Roofline 条目，此处不重复），单位计算量的访存能量贡献正比于 $$1/I$$。这意味着能耗帕累托前沿的形状随 $$I$$ 分段：低算术强度区间，优化访存合并与缓存复用直接压低 $$E$$；高算术强度区间，降低 $$f$$ 与 $$V$$ 的收益超过任何访存优化。一个具体例子：同一归约 kernel，把全局内存往返从两次降到一次（片上累加替代中间落盘），在低 $$I$$ 下能耗下降主要来自 $$\bar P_{\text{mem}}$$ 项；而在把计算密度提高一个量级后，同样的访存优化对 $$E$$ 的边际贡献被 $$\bar P_{\text{dyn}}$$ 淹没。这解释了为什么单一 kernel 的能耗结论不能跨算术强度区间外推。

代价在于分项测量本身：$$\bar P_{\text{static}}$$ 需要空闲态基线，$$\bar P_{\text{dyn}}$$ 与 $$\bar P_{\text{mem}}$$ 的分离通常依赖硬件计数器而非直接功率读数，计数器读数与真实功率之间的映射系数需要标定，标定实验本身消耗测量窗口。在多轮优化循环里，每轮都做完整标定不可行，实践上把标定做成一次性常量，代价是跨 kernel 比较时该项误差不可消除。

三 · 帕累托支配的离散化：前沿是采样出来的

目标写成 $$\min\ (\text{latency}, E)$$ 是连续多目标问题的记号，但工程上拿到的永远是一组离散候选点。支配关系定义为：点 $$a$$ 支配 $$b$$ 当且仅当 $$\text{lat}(a)\le \text{lat}(b)$$ 且 $$E(a)\le E(b)$$，且至少一项严格不等。前沿即不被任何其他点支配的子集。离散化的第一层近似是候选集有限：搜索只能在前沿的采样版本上做决策，真实前沿上未被采到的点永远不可见。第二层近似是测量噪声：$$\text{lat}$$ 与 $$E$$ 都带置信区间（计时噪声的处理见对应条目），当两点在噪声范围内不可区分时，支配判定退化为随机判定。

一个可操作的判定伪代码思路是：对每个候选重复 $$k$$ 次测量，取 $$\text{lat}$$ 的中位数与 $$E$$ 的中位数作为坐标，再用区间下界与上界做保守支配检验——只有当 $$a$$ 的时延上界不超过 $$b$$ 的时延下界、且 $$a$$ 的能耗上界不超过 $$b$$ 的能耗下界时才判定支配，否则两点并存于前沿。保守判定的代价是前沿变胖：并存点增多，下游选择需要更多人工或启发式介入，而 $$k$$ 次重复直接把单点测量成本乘以 $$k$$。在 agent 驱动的搜索里，这个乘数转化为每轮迭代可评估的候选数量下降，进而影响搜索广度。

离散化还引入一个不易察觉的偏置：候选生成器倾向于产生时延相近、能耗差异小的变体（例如只调 tile 大小），于是前沿在时延轴上密集、在能耗轴上稀疏，看起来像一条陡峭曲线，实际只是采样密度的投影。具体例子：同一矩阵乘的三个变体，时延分别为 100、102、105 个相对单位，能耗分别为 1.00、0.97、0.93 个相对单位；若只报时延最优者，会丢掉能耗低 7% 但时延高 5% 的点，而后者在功耗受限场景下才是正确选择。判定时必须同时保留两个坐标，任何单目标排序都会系统性剪掉前沿的另一端。

四 · 漂移项：DVFS 与温度如何破坏可加性

把 $$E\approx\bar P T$$ 用于跨配置比较时，隐含假设 $$\bar P$$ 与 $$T$$ 可独立测量再相乘。DVFS 打破这个假设：频率 $$f$$ 是 $$u$$ 与功率预算的函数，$$T$$ 随 $$f$$ 变化的同时 $$\bar P$$ 也随 $$f$$ 变化，两者通过控制环路耦合。写成链式关系，$$\frac{dE}{df}=\frac{\partial \bar P}{\partial f}T+\bar P\frac{\partial T}{\partial f}$$，两项符号相反：降频降低功率但拉长时延，净效应取决于 $$T$$ 对 $$f$$ 的敏感度是否超过 $$\bar P$$ 对 $$f$$ 的敏感度。在访存受限区间，降频几乎不拉长时延却显著降功率，$$E$$ 单调下降；在计算受限区间，时延近似反比于 $$f$$，乘积可能持平甚至上升。这条分界线正是能耗帕累托前沿上出现拐点的机制来源。

温度引入第二重漂移：漏电功率随结温上升而增加，$$\bar P_{\text{static}}(T_j)$$ 是温度的增函数，而温度又是先前功耗的积分结果。于是同一 kernel 连续跑两次，第二次的能耗读数系统性偏高，偏差量取决于两次之间的散热间隔与芯片热容。这不是随机噪声，是可预测的单调漂移，用重复测量取中位数无法消除，只能靠固定散热窗口与随机化执行顺序来摊平。代价是实验吞吐：固定散热窗口意味着两次测量之间必须插入冷却等待，单机每小时可完成的独立测量数下降，搜索循环的墙钟成本上升。

具体例子：某 kernel 在冷态测得时延 50 个相对单位、能耗 1.0 个相对单位；在同一芯片上热态重测，时延 52、能耗 1.06。若把冷态数据与另一 kernel 的热态数据放进同一前沿图，会得出前者全面占优的错误结论，而真实差异可能只是热状态不同。跨硬件比较同理失效：不同硬件的能效曲线不可直接比较，因为 $$\bar P_{\text{static}}$$ 的工艺基数、DVFS 策略与散热设计都不同，把两块卡的 $$E$$ 绝对值放在同一张表里，等于把三个未标定的常量混在一起。

五 · 推导关键步的可验证性：从公式回到 kernel 属性

公式链的每一跳都应能对应到一个可观测的 kernel 属性，否则推导只是符号游戏。第一跳 $$E=\int P\,dt\to \bar P T$$ 对应窗口定义与采样率；第二跳 $$\bar P\to \bar P_{\text{static}}+\bar P_{\text{dyn}}+\bar P_{\text{mem}}$$ 对应硬件计数器与空闲基线；第三跳 $$\bar P_{\text{dyn}}\to \alpha C V^2 f u$$ 对应占用率、频率与活动因子；第四跳支配判定对应测量重复数与区间估计。任何一跳缺少对应观测，该跳之后的结论就只能定性表述。

把这条链用于 agent 生成的 kernel 时，验证顺序应当是自底向上：先确认占用率与频率在测量窗口内稳定（否则 $$u$$、$$f$$ 不是常量，乘积形式失效），再确认窗口边界一致，最后才比较 $$E$$。一个具体例子：某 Triton 生成的 kernel 在 profiler 里显示占用率随时间从 30% 爬升到 70%，此时用全程平均占用率代入 $$\bar P_{\text{dyn}}$$ 公式会低估瞬态功率，进而低估 $$E$$；正确做法是把窗口切成占用率稳定的子段分别积分再求和，代价是分段边界的判定逻辑与额外后处理。这类分段积分的实现复杂度远高于单点乘法，是能耗建模在工程上难以规模化的直接原因。

另一个可验证性缺口在 $$\alpha$$：活动因子无法从 kernel 源码直接读出，只能由指令混合与分支行为间接估计。当 agent 通过改写循环结构降低 $$\alpha$$ 时，它同时可能改变 $$u$$ 与 $$T$$，三个量同向或反向变动，单次测量无法归因。要拆开，需要在固定 $$f$$ 与 $$u$$ 的条件下做受控变体对比，这又把实验数量乘以变体维度。能耗帕累托的搜索成本，本质上来自这种多维受控对比的组合爆炸，而不是来自单次测量的开销。

六 · 近似的边界：什么时候乘积形式必须放弃

乘积形式 $$E\approx\bar P T$$ 在两类情形下必须放弃。第一类是 $$T$$ 与功率瞬态同量级：当 kernel 时延接近 DVFS 响应时间常数，频率在 kernel 执行期间尚未稳定，$$\bar P$$ 不是稳态值而是过渡段的平均，此时 $$E$$ 对窗口起点极端敏感，任何跨 kernel 比较都失去意义。第二类是功率预算触发降频保护：当瞬时功率触及上限，硬件主动降频，$$T$$ 被拉长而 $$\bar P$$ 被钳制，乘积形式给出的 $$E$$ 会系统性偏低，因为被钳制期间的功率曲线不是自由演化而是受控截断。

这两类情形对应帕累托前沿上的不可比区域：前沿的某些段落在 DVFS 过渡区，点与点之间的能耗差被控制环路抹平，排序结果由测量窗口的微小偏移决定而非 kernel 属性决定。工程判断是：把这类点标记为不可比，而不是强行排序。代价是前沿覆盖率下降，agent 可用的有效反馈信号减少，多轮搜索在这些区域收敛更慢；收益是避免把噪声当成优化信号，防止搜索朝着窗口偏移的方向而不是真实能效的方向漂移。

最终落在具体机制上：能耗帕累托的公式链不是一条可以直接代入数值的恒等式，而是一组带前提的近似，每个前提对应一个必须显式记录的测量约定——窗口边界、采样率、散热状态、频率稳定性、支配判定的保守程度。这些约定共同决定了前沿的形状与可信度，而 kernel 本身的优化只在前沿内部移动点，不改变前沿的测量学基础。把约定写进实验记录，比把公式写进文档更能约束 agent 的行为。

平均功率近似的边界：采样窗口、DVFS 漂移与跨硬件不可比

把 E=∫P(t)dt 折叠成 Ē·T 的那一刻，误差就被写进了分母。瞬时功率的采样在硬件上依赖板载分流电阻与 PMIC 遥测，单次采样周期通常在毫秒量级，而一个 kernel 的 burst 段可能只有几十微秒——采样窗口比被采对象还宽，Ē 实际是若干窗口的算术平均，把启动斜坡与尾部排空一并抹平。工程上可行的折中是按 SM 活跃度加权的分段平均：以 NCU 的 sm__cycles_active 与 dram__bytes 为权重把 T 切成 K 段，每段用一次遥测读数代表，误差量级由段内功率方差决定，而不是由采样率决定。代价是每次评测多出 K 次带外读取，K 取 8–16 时单 kernel 评测时延增加约一个数量级于纯计时路径，却仍远低于逐指令功耗仿真。

更麻烦的是 Ē 与 T 并非独立变量。DVFS 控制器以毫秒级时间常数响应利用率，一个被 agent 优化得更短的 kernel 往往在更高频率档位上完成，Ē 上升而 T 下降，两者在帕累托平面上朝相反方向移动——这正是「提速但能耗更高」的机制来源，而非测量噪声。温度是第二个漂移源：同一二进制在冷片与热片上跑出的 Ē 差异来自漏电与频率回落，若评测队列不固定预热轮次与散热状态，跨轮比较的方差会吞掉真实的前沿位移。因此 RL 奖励里若直接使用原始 Ē，等价于给策略注入一个随机器状态漂移的偏置项。

跨硬件比较的失效更彻底：能效曲线的斜率由工艺、显存类型与供电拓扑共同决定，A 卡上 Ē 低 10% 的 kernel 在 B 卡上可能反向。可迁移的只有无量纲量——把 Ē 对同卡同频的基线 kernel 归一，得到相对能效比 r=E/E_base，再与 T/T_base 组成二维坐标；绝对焦耳数只在本卡闭环内使用。判据上，当 r 的相对标准差超过前沿两点间距时，该维度的排序不可信，应退化为仅按 latency 排序并在日志中标记能耗维度失效。

近似引入的偏差系统代价
单窗口平均功率抹平 burst 与排空段遥测读取 K 次，评测时延上升
固定频率假设DVFS 使 Ē、T 反相关需锁频或记录频率轨迹
