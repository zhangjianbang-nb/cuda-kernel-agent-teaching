一 · 逐项解剖：$s_\infty$、$c$、$\alpha$ 各自在说什么

公式 $\mathbb{E}[\max_{i\le n}s_i]\approx s_\infty-c\,n^{-\alpha}$ 的每一项都对应一个可被工程测量的量，而不是抽象符号。$s_\infty$ 是预算趋于无穷时的渐近得分，它的物理含义是“在给定采样分布、给定评分器、给定验证预算下，这条生成路径能达到的天花板”。注意它并非任务的理论最优——它被采样器覆盖的支撑集和 oracle 的判定粒度共同封顶：若评分器只做数值容差比对，$s_\infty$ 就被容差宽度锁住；若采样温度过低，$s_\infty$ 被模式坍缩锁住。$c$ 是“首轮差距”，即 $n=1$ 时与渐近线的距离量级，它衡量的是单次采样的质量缺口；$c$ 大意味着第一发离天花板远，加轮数的绝对空间大。$\alpha$ 是衰减指数，控制收益收敛的陡峭程度，它才是决定“加轮数是否划算”的核心参数。三者的关系可以写成 $n=1$ 时 $\mathbb{E}[s_1]=s_\infty-c$，因此 $c$ 与 $s_\infty$ 不是独立可调的：拟合时必须联合估计，否则把 $c$ 估小会把 $\alpha$ 估大，进而高估边际收益。

一个具体例子：某 GEMM 调优任务上，采样器在 $n=1$ 时得分 0.42，$n=8$ 时 0.61，$n=64$ 时 0.68，用三点拟合得到 $s_\infty\approx0.71$、$c\approx0.29$、$\alpha\approx0.55$。这三个数直接告诉我们：第 64 轮到第 128 轮的期望增益约为 $c\alpha n^{-\alpha-1}\approx0.29\times0.55\times64^{-1.55}$，量级在千分之几，而多跑 64 轮采样的 GPU 时延是实打实的。这就是“边际低于成本”的定量表达，不需要任何模糊措辞。

二 · 推导关键步：从次序统计量到幂律近似

推导的起点是次序统计量。设 $n$ 个采样得分独立同分布，累积分布为 $F$，则最大值的期望为 $\mathbb{E}[\max_{i\le n}s_i]=\int_0^\infty \left(1-F(s)^n\right)\mathrm{d}s$（对非负得分）。关键步在于对 $F$ 的上尾做变换：令 $u=1-F(s)$ 为上尾概率，当 $s$ 接近 $s_\infty$ 时上尾通常呈幂律 $u\propto(s_\infty-s)^{\beta}$，代入积分并做变量替换，得到 $\mathbb{E}[\max]\approx s_\infty-c\,n^{-1/\beta}$，即 $\alpha=1/\beta$。这一步是全部推导的枢纽：$\alpha$ 不是拟合出来的自由参数，而是上尾厚度的倒数——上尾越薄（$\beta$ 大），$\alpha$ 越小，收敛越慢，加轮数越不划算。反过来，若评分器把大量采样打成同一档（离散化严重），上尾被人为截断成阶梯，幂律近似失效，$\alpha$ 的估计会系统性偏大。

推导中第二个关键步是把“独立同分布”换成“可交换但相关”。若采样间相关系数为 $\rho$，有效样本数近似为 $n_{\text{eff}}\approx n/(1+(n-1)\rho)$，代入同一公式得 $\mathbb{E}[\max]\approx s_\infty-c\,n_{\text{eff}}^{-\alpha}$。当 $n$ 增大时 $n_{\text{eff}}$ 饱和于 $1/\rho$，收益曲线出现硬平台——这解释了为什么高温多样采样在小 $n$ 时收益明显、在大 $n$ 时突然失效。伪代码思路：对每轮采样记录得分，按 $n$ 分组算经验最大值，对 $\log(s_\infty-\hat{s}_n)$ 与 $\log n$ 做线性回归，同时用 $\rho$ 的估计值修正 $n_{\text{eff}}$，残差结构若呈系统性弯曲则说明单一幂律不够。

代价在这里已经显形：拟合本身要消耗采样预算，每组 $n$ 至少需要若干次重复才能把经验最大值的方差压下来，而最大值的方差随 $n$ 增大而增大（极值分布尾部厚），这意味着大 $n$ 区间的拟合点最不可靠，却恰恰是决定“是否继续加预算”的区间。工程上的做法是把拟合预算前置到小 $n$ 区间，用 $\alpha$ 的外推代替大 $n$ 实测，代价是外推误差。

三 · 离散化与近似：三处必须交代的失真

第一处失真是得分离散化。评分器输出的是通过/不通过或有限档位，$F$ 是阶梯函数，上尾不是连续幂律。此时 $\mathbb{E}[\max]$ 的积分退化为求和，$\mathbb{E}[\max]=s_\infty-\sum_k \Delta_k (1-F_k)^n$，每一项都以 $n$ 的指数衰减，整体是多个指数项的叠加而非单一幂律。用单幂律拟合这种曲线，在小 $n$ 段会低估、在大 $n$ 段会高估，直接后果是把“该停”的预算判成“还能再榨”。第二处失真是采样预算的整型化：$n$ 只能取整数，边际收益应写成差分 $\mathbb{E}[\max_{i\le n+1}]-\mathbb{E}[\max_{i\le n}]$ 而非导数，两者在 $n$ 小时差异可观，用导数会高估早期边际。第三处失真是评分器噪声：若单次评分有方差 $\sigma^2$，经验最大值被噪声向上偏置，$\hat{s}_\infty$ 被抬高，$\alpha$ 被压低，收益曲线看起来比真实更“长尾”。

一个具体例子：某 Triton kernel 的正确性 oracle 只做 allclose 判定，得分是 0/1。此时 $F$ 只有两级，$\mathbb{E}[\max]$ 就是 $1-(1-p)^n$，其中 $p$ 是单次通过率。这条曲线在 $p$ 小时近似 $np$（线性），在 $p$ 大时指数饱和，与幂律形状完全不同。若硬套幂律，拟合出的 $\alpha$ 没有物理意义，据此做的预算决策就是把“通过率已经很高、再加轮数只是重复成功”误判为“还有长尾可挖”。正确做法是先判断评分器粒度：粒度粗于得分动态范围时，改用通过率模型而非幂律模型。

代价层面：离散化使拟合所需样本数上升，因为阶梯函数的每个台阶都要足够重复才能估准；评分噪声则要求对同一候选重复评分取均值，直接乘以评分调用次数。这两项都在 token 与 GPU 时延上计费，且随 $n$ 增大而放大——大 $n$ 区间每个数据点的获取成本本身就是小 $n$ 区间的数倍。

四 · 边际公式的展开与停机判据

对 $\mathbb{E}[\max]\approx s_\infty-c\,n^{-\alpha}$ 求导得边际 $\partial_n\mathbb{E}=c\alpha\,n^{-\alpha-1}$。这个式子把停机判据变成一个可比较的量：当 $c\alpha\,n^{-\alpha-1}\cdot V$（$V$ 为单位得分对应的端到端收益）低于单轮采样的成本 $C_{\text{round}}$（GPU 时延 + 评分调用 + 上下文 token）时停机。整理得停机轮数 $n^\*\approx\left(c\alpha V/C_{\text{round}}\right)^{1/(\alpha+1)}$。这个闭式解的价值在于它把“预算该给多少”从调参变成代入：$\alpha$ 越大，$n^\*$ 越小，因为收益衰减快；$C_{\text{round}}$ 越大（例如每轮都要跑 NCU profile 做验证），$n^\*$ 越小。注意 $n^\*$ 对 $\alpha$ 的敏感度是非线性的，$\alpha$ 估错 20% 会让 $n^\*$ 偏移数十个百分点，这也是为什么拟合必须带置信区间而非点估计。

一个具体例子：某 reduce kernel 的调优中，单轮采样成本约为一次编译加一次计时，$V$ 取“每提升 0.01 得分对应端到端时延下降的折算值”。若拟合得 $\alpha=0.5$、$c=0.3$，代入得 $n^\*$ 落在几十轮量级；若把验证从“仅计时”升级为“计时 + NCU 指标核对”，$C_{\text{round}}$ 上升数倍，$n^\*$ 相应降到十几轮。这不是定性判断，而是同一公式下成本项的替换。

代价必须写清：停机判据依赖 $V$ 的估计，而 $V$ 本身来自端到端测量，带有计时噪声；把噪声代入 $n^\*$ 会放大误差。工程上的稳妥做法是对 $V$ 取下界估计，使 $n^\*$ 偏保守——宁可少跑几轮，也不要在边际已经低于成本时继续烧 GPU。

五 · 失效条件的公式侧诊断

任务难度分布不均匀时，单一幂律不够，因为 $\mathbb{E}[\max]$ 是多个难度簇的最大值期望的混合：$\mathbb{E}[\max]=\sum_j w_j\left(s_{\infty,j}-c_j n^{-\alpha_j}\right)$，每个簇有自己的天花板和指数。混合曲线在 $\log n$ 坐标下不是直线而是分段弯曲，早期由易簇主导（$\alpha$ 大、收敛快），后期由难簇主导（$\alpha$ 小、拖长尾）。诊断方法：对残差做分段拟合，若两段的 $\alpha$ 差异显著，就应把预算按簇分配而非全局加轮数——把预算投给难簇的边际更高。采样相关的情形已在第二节给出 $n_{\text{eff}}$ 修正，诊断信号是收益曲线提前饱和且饱和点随温度升高而右移。best-of-n 放大 reward hacking 的情形则表现为：得分随 $n$ 单调上升但审计通过率下降，此时 $\mathbb{E}[\max]$ 的上升是评分器被利用的假象，公式本身没错，错在 $s_i$ 的度量对象。

一个具体例子：混合了 softmax 与 layernorm 两类 kernel 的基准上，softmax 簇在十几轮内接近天花板，layernorm 簇在几十轮后仍在爬升。全局拟合得到一条看似平滑的幂律，但分段看两簇的 $\alpha$ 相差一倍以上。按全局 $\alpha$ 算出的 $n^\*$ 对 softmax 是浪费，对 layernorm 是过早停机。正确做法是把 $n$ 的分配写成带约束的优化：$\max\sum_j w_j\Delta_j(n_j)$ 受 $\sum n_j\le N$ 约束，拉格朗日条件给出各簇边际相等时最优，即 $c_j\alpha_j n_j^{-\alpha_j-1}$ 全部相等。

代价：分段拟合需要每簇足够的样本，采样成本按簇数倍增；审计通过率的测量又要额外调用评分器。这些开销在小预算下可能吞掉收益本身，因此失效诊断应设触发门槛——只有当全局拟合残差超过阈值时才启动分段。

六 · 拟合流程的工程化：从数据到判据

把上述公式落成流程，需要四步且每步都带代价。第一步，按几何级数取 $n\in\{1,2,4,8,\dots\}$ 采样，每组重复 $R$ 次以估计经验最大值的均值与方差；几何取点的理由是幂律在 $\log n$ 上线性，等距取点会让大 $n$ 段样本过密而小 $n$ 段过疏。第二步，用加权最小二乘拟合 $\log(\hat{s}_\infty-\hat{s}_n)$ 对 $\log n$ 的直线，权重取各组方差倒数；$\hat{s}_\infty$ 先用最大观测得分加一个由极值理论给出的上偏修正，再迭代。第三步，检查残差：系统性弯曲指向混合分布，饱和指向相关采样，尾部上翘指向评分噪声。第四步，代入停机判据得 $n^\*$，并把 $n^\*$ 与已消耗预算比较，决定继续还是收敛。

伪代码思路：for n in geomspace: scores[n]=repeat_sample(R); fit(s_inf,c,alpha)=wls(log(s_inf-scores),log(n)); if residual_bend: split_by_cluster(); n_star=(c*alpha*V/C_round)**(1/(alpha+1))。这段流程的 token 成本主要在第 1 步的采样与第 4 步的验证调用，编译时间成本在每次采样都要重新生成并编译 kernel 时计入 $C_{\text{round}}$；若采样器缓存了编译产物，$C_{\text{round}}$ 下降，$n^\*$ 右移。工程判断落在最后一步：$n^\*$ 是估计值而非真值，实际停机应取 $n^\*$ 的下置信界，并在每次新增一轮后重估 $\alpha$——因为 $\alpha$ 的估计随数据积累而漂移，早期估出的 $n^\*$ 不应被当作一次性决策。

幂律拟合的适用边界：从独立同分布假设到相关采样

公式 $\mathbb{E}[\max_{i\le n}s_i]\approx s_\infty-c\,n^{-\alpha}$ 的推导起点是次序统计量：若 $n$ 个样本独立同分布、CDF 为 $F$，则最大值的期望为 $\int_0^\infty \left(1-F(s)^n\right)\mathrm{d}s$。对 $F$ 在尾部做指数近似 $1-F(s)\approx k(s_\infty-s)^{\beta}$，积分换元后得到 $s_\infty-c\,n^{-1/\beta}$，即 $\alpha=1/\beta$。关键步在于两个近似同时成立：尾部必须足够光滑且单调，$n$ 必须大到使 $F(s)^n$ 的支撑集中在 $s_\infty$ 附近。边际收益 $\partial_n\mathbb{E}=c\alpha\,n^{-\alpha-1}$ 随 $n$ 单调下降，这是“收益递减”的数学来源，但它下降的快慢完全由 $\alpha$ 决定，而 $\alpha$ 是拟合出来的，不是任务的内禀常数。

失效条件一：难度分布不均匀。真实 kernel 任务池里，GEMM 类与 reduction 类的得分分布尾部形状不同，用单一幂律拟合整个池子会把简单任务的饱和段和困难任务的缓慢爬升段混在一起，$\alpha$ 被低估，于是公式预测“还能涨”，实际早已进入平台。工程上应按任务族分层拟合，每层单独估 $\alpha$，再按采样配额加权合成总期望；代价是分层后每层样本量变小，$\alpha$ 的置信区间变宽，需要更多轮数才能把拟合误差压到可接受范围，这本身又消耗 GPU 时。失效条件二：采样之间相关。同一 prompt 下多次采样共享前缀，解码温度低时样本高度相似，独立同分布假设破裂，实际 $\mathbb{E}[\max]$ 低于公式预测。此时有效样本数 $n_{\text{eff}}<n$，可用 $n_{\text{eff}}\approx n/(1+(n-1)\rho)$ 修正，$\rho$ 为样本间得分相关系数；$\rho$ 接近 1 时加轮数几乎不涨分，公式给出的边际收益是虚假的。

失效条件三：best-of-n 放大 reward hacking。$n$ 增大时最大值取自分布尾部，而尾部恰恰是奖励模型误判最集中的区域——分数越高，越可能是钻了评分脚本空子的 kernel（例如跳过边界检查、用未定义行为换速度）。公式只描述分数上界，不描述分数与真实正确性的偏离；当 $n$ 超过某个阈值，$\mathbb{E}[\max s_i]$ 继续上升但审计通过率下降，此时应把预算从“加轮数”转向“加审计”。系统代价上，每轮采样的成本是生成 token 加编译加 profile 的固定开销，而边际收益按 $n^{-\alpha-1}$ 衰减，二者相交处即为预算拐点；拐点位置对 $\alpha$ 敏感，$\alpha$ 估错一档，拐点可能偏移数倍，导致要么过早停止错过真实提升，要么在平台上空烧 GPU 时。

拟合曲线的适用边界：何时幂律不再描述搜索收益

该式把第 n 轮搜索的期望最优得分写成渐近上限减去一个衰减项，边际收益就是对 n 求偏导，得到 c·α·n−α−1。推导的关键一步是把“第 n 次采样超过此前最优”的概率近似为 n−α−1 量级，这等价于假设得分分布的右尾服从幂律、且各次采样独立同分布。离散化只发生在把连续积分换成对 n 的求和：当 n 较小时，求和与积分的偏差不可忽略，拟合出的 α 会被前几轮的高收益拉偏，因此小预算区间的数据点不应参与拟合。

失效条件有三类，且都会在工程上留下可观测的痕迹。任务难度分布不均匀时，单一幂律无法覆盖整个 n 区间，表现为残差随 n 单调漂移，此时应按难度分层拟合，每层各自有 c 与 α。采样之间相关时（温度过低、提示几乎相同、同一 seed 族），独立同分布假设破裂，实际边际收益比公式预测衰减得更快，公式会高估追加轮数的价值。best-of-n 放大 reward hacking 则让 s∞ 本身失去意义：分数越高的样本越可能利用评分器的漏洞，曲线看起来仍在上升，但上升的是被欺骗的度量而非真实正确性。

系统代价体现在拟合成本与决策风险两侧。为估计 α 需要覆盖足够宽的 n 区间，意味着至少要在几个数量级上各跑一批采样并逐一验证正确性，验证开销随样本数线性增长，且每次验证都要占用 GPU 时间与显存；若用 NCU 逐样本 profile 来剔除异常样本，编译与采集时延会进一步放大。工程判断是：把边际收益与单轮采样的实测成本（含验证）比较，当边际得分增量折算的正确率提升低于该成本对应的阈值时停止加轮，而不是等曲线拟合完成；同时保留一份独立审计样本，专门检查高分样本的真实性，防止 s∞ 被 reward hacking 抬高。
