一 · 题干的三层结构：谁在抽样、抽什么、抽样结果喂给谁

「隐藏 shape 分布抽样」这类题面通常不会把三件事写清楚，而解题的第一步恰恰是把它们从题干里拆出来。第一层是抽样主体：是评测框架在离线构造 benchmark 时抽样，还是 agent 在搜索过程中在线抽样候选 shape 去试探 kernel 的鲁棒性。第二层是被抽的对象：抽的是 shape 元组本身（M、N、K、batch、seq_len 等），还是抽的是这些维度背后的分布参数（例如某个维度的取值区间、对齐约束、长尾比例）。第三层是抽样结果的消费者：抽样得到的 shape 集合是拿去算期望性能、算最坏情况性能、还是拿去决定搜索预算该给哪个候选 kernel 分配多少编译与 profile 次数。三层不清，后面所有公式都会套错变量。

题干里常见的诱导性措辞是「隐藏」二字。它至少对应两种工程现实：其一是评测方持有真实分布但不公开，被测方只能看到有限采样；其二是分布本身在漂移，线上流量与离线 benchmark 的 shape 分布不一致。这两种「隐藏」在公式上的体现完全不同——前者是估计误差问题（样本均值对真实均值的偏差），后者是分布偏移问题（重要性加权或重采样）。读题时必须先判定属于哪一种，否则会把一个偏移问题当成估计问题去加大样本量，预算花光而偏差不减。

考点因此可以归为三类：其一，能否写出抽样分布的概率质量函数并正确区分「按 shape 均匀抽」与「按流量加权抽」；其二，能否把抽样结果正确地折算成期望收益或期望代价，并说明这个期望对搜索预算的边际影响；其三，能否给出置信区间或样本量下界，从而判断当前采样是否足以支撑上线决策。解题路径建议固定为：先画变量表（哪些是随机变量、哪些是待估参数、哪些是决策变量），再写目标量（期望、分位数、最坏情况），最后才选估计器与样本量。

二 · 核心公式的逐项拆解：期望性能是加权和，不是算术平均

该类题的核心公式通常形如「在隐藏分布下 kernel 的期望代价」，其标准写法是

$$\mathbb{E}_{s\sim p}[C(s)]=\sum_{s\in\mathcal{S}} p(s)\,C(s),\qquad \hat{\mu}=\frac{1}{n}\sum_{i=1}^{n} C(s_i),\ s_i\sim p$$

逐项解释：$s$ 是一个 shape 元组，$\mathcal{S}$ 是候选 shape 空间（通常是离散的，因为维度取值受对齐约束限制），$p(s)$ 是隐藏分布的质量函数，$C(s)$ 是在该 shape 下测得的代价（可以是时延、显存峰值、编译时间或 token 消耗，取决于题干问的是哪一类）。$\hat{\mu}$ 是用 $n$ 个样本做的蒙特卡洛估计。这里第一个易错点是：如果 $p$ 不是均匀分布，那么「把 benchmark 里所有 shape 的时延取算术平均」得到的是 $\frac{1}{|\mathcal{S}|}\sum C(s)$，它与 $\mathbb{E}_p[C]$ 的差是一个加权偏差，量级取决于 $p$ 与均匀分布的总变差距离。第二个易错点是 $\mathcal{S}$ 的边界：题干若给出「隐藏」二字，往往意味着 $\mathcal{S}$ 中存在若干未被采样覆盖的 shape，此时 $\hat{\mu}$ 只估计了支撑集上的条件期望，外推需要额外的假设。

与之配套的还有方差项，用于回答「采多少够」：

$$\mathrm{Var}(\hat{\mu})=\frac{\sigma^2}{n}\left(1+\frac{n-1}{N}\right)\ \text{（有限总体修正）},\qquad n\ge \frac{z^2\sigma^2}{\epsilon^2}$$

其中 $\sigma^2$ 是 $C(s)$ 在 $p$ 下的方差，$N$ 是有限总体大小（若 shape 空间可枚举则 $N=|\mathcal{S}|$），$\epsilon$ 是允许的估计误差，$z$ 是置信水平对应的分位数。这个公式给出的工程代价非常直接：$\sigma^2$ 大意味着 shape 之间的性能差异剧烈（例如 K 维度的对齐与否导致一个 kernel 走 fast path 还是 fallback），此时要把 $\epsilon$ 压到一半，样本量得翻四倍。而每个样本的代价不是零——一次采样往往意味着一次编译加一次 NCU profile，编译时间与 profile 时延共同构成单样本成本，于是总预算 $B\approx n\cdot(c_{\text{compile}}+c_{\text{profile}})$ 与精度要求直接对冲。

第三个必须写出的项是分位数或最坏情况，因为上线判断常常不看均值而看尾部：

$$q_{1-\alpha}=\inf\{t:\ \Pr[C(s)\le t]\ge 1-\alpha\},\qquad \widehat{q}_{1-\alpha}=C_{(k)},\ k=\lceil (1-\alpha)n\rceil$$

顺序统计量估计分位数的收敛速度远慢于均值，$\alpha$ 越小所需 $n$ 越大，这是「隐藏分布」题里最容易被忽略的预算黑洞：想把 P99 时延估准，样本量需求比估均值高一个量级以上。若题干要求「保证线上不出现超时」，考点就落在这一项上，而不是均值项。

三 · 算例：一个二维 shape 空间上的抽样与预算折算

设 shape 空间由两个维度构成：$M\in\{64,128,256,512\}$，$K\in\{64,128,256,512\}$，共 16 个候选点。题干给定隐藏分布 $p$ 的一个可操作描述：$M$ 与 $K$ 独立，$M$ 取小值的概率高（小 batch 流量占多数），$K$ 在 128 与 256 上集中，512 为长尾。解题时不要求知道具体概率值，而要求写出「若按均匀抽样，偏差有多大」以及「若按 $p$ 加权抽样，预算如何分配」。这就是典型的「公式逐项 + 算例」组合考法。

第一步，列出 $C(s)$ 的定性结构：$K$ 为 64 或 128 时，向量化加载能整除，走 fast path；$K=256$ 时若 tile 划分不当会出现边界分支；$K=512$ 时长尾且可能触发寄存器压力导致的 occupancy 下降。于是 $C(s)$ 在 $K$ 方向上呈阶梯状，方差 $\sigma^2$ 主要来自 $K$ 的跳变，而非 $M$ 的平滑变化。这个结构判断决定了分层抽样是比简单随机抽样更优的估计器：按 $K$ 分层，层内方差小，层间差异大，分层估计的方差约为 $\sum_k w_k^2\sigma_k^2/n_k$，在同样总样本量下显著低于 $\sigma^2/n$。

第二步，算预算。设单样本成本由编译与 profile 两部分构成，编译时间随 shape 变化不大但随 kernel 变体数量线性增长，profile 时延随 $C(s)$ 本身增长。若题干要求均值估计误差不超过某个相对比例，则 $n$ 由第二节的样本量下界给出；若同时要求 P99 分位数，则 $n$ 需按分位数收敛速度再放大。工程判断在这里出现分岔：如果搜索阶段只需要在候选 kernel 之间排序，那么均值估计的绝对精度不重要，重要的是配对比较——在同一批抽样 shape 上跑所有候选，用差值 $\Delta(s)=C_A(s)-C_B(s)$ 的均值做决策，此时公共方差被抵消，所需 $n$ 远小于独立估计各自均值所需的 $n$。这是该算例最值得写的考点：预算不该平均分给「估每个候选的绝对性能」，而该分给「估候选之间的差」。

第三步，上线判断。若题干给出「线上 P99 时延不得超过某阈值」的约束，则决策量是 $\widehat{q}_{0.99}$ 与阈值的比较，且必须报告该估计的置信上界而非点估计。顺序统计量的置信区间可由二项分布精确构造：$C_{(k)}$ 的覆盖概率对应参数为 $(n,1-\alpha)$ 的二项尾概率，样本量不足时区间极宽，此时正确的工程动作不是「再采几个点看看」，而是明确指出当前采样不足以支撑上线判断，需要把预算从搜索阶段挪到验证阶段。

四 · 抽样结果如何回流到搜索预算：从估计量到分配策略

题干若把「抽样」与「搜索预算」并列，考点就落在把估计量当作分配信号这一环。常见机制是：agent 维护若干候选 kernel 变体（不同 tile 大小、不同向量化宽度、不同流水深度），每轮从隐藏分布中抽一批 shape，对每个候选在该批 shape 上测代价，然后按某种规则决定下一轮给哪个候选更多编译与 profile 配额。形式化地，若把总预算 $B$ 分成 $T$ 轮，每轮给候选 $j$ 分配 $b_j^{(t)}$，则分配规则可写成

$$b_j^{(t+1)}\propto \exp\!\left(-\eta\,\hat{\mu}_j^{(t)}\right)\quad\text{或}\quad b_j^{(t+1)}\propto \hat{\sigma}_j^{(t)}\sqrt{\tfrac{\log T}{n_j^{(t)}}}$$

前者是按当前估计均值做软最大化（ exploitation 偏向），后者是置信上界型规则（ exploration 偏向，$\hat{\sigma}_j$ 是候选 $j$ 在抽样 shape 上的代价标准差，$n_j$ 是它已获得的样本数）。逐项看：$\eta$ 控制分配的温度，$\hat{\mu}_j$ 是候选 $j$ 在隐藏分布下的期望代价估计，$\hat{\sigma}_j\sqrt{\log T/n_j}$ 这一项刻画的是「还没测够因而可能被低估」的程度。这个规则的代价是明确的：exploration 项让预算流向高方差候选，而高方差往往来自它对某些 shape 走 fallback 路径，于是这些候选的编译时间与 profile 时延都更高，单样本成本上升，总轮数 $T$ 被迫压缩。

具体例子：若候选 A 在 $K=128$ 上极快但在 $K=512$ 上触发寄存器溢出导致 occupancy 减半，候选 B 在所有 $K$ 上都中等但无跳变。按均值规则，若抽样恰好偏向小 $K$，A 会被过度分配预算；按置信上界规则，A 的高 $\hat{\sigma}$ 会让它持续获得配额去覆盖长尾 shape，直到 $\hat{\sigma}$ 收敛。工程判断是：隐藏分布若已知长尾存在，分配规则必须显式包含方差项，否则抽样偏差会与分配偏差叠加，形成「越抽越偏」的正反馈。这一条是该类题在搜索预算维度上的核心考点，也是与纯均值估计题的分水岭。

五 · 正确性代价与验证 oracle 在抽样题中的位置

抽样不只服务于性能估计，也服务于正确性验证。题干若提到「隐藏 shape 分布」与「验证」，考点是把抽样得到的 shape 当作正确性 oracle 的输入域：对每个抽到的 shape，用参考实现（CPU 或高精度 GPU 实现）算出期望输出，与候选 kernel 的输出比对，容差按数据类型与累加顺序设定。这里的代价项与前几节不同——它不是时延或显存，而是参考实现的执行时间与比对开销，在大 shape 上参考实现可能比被测 kernel 慢一个量级以上，于是验证预算成为总预算中的独立一块。

抽样策略在此处的影响是覆盖度：均匀抽样在维度组合多时极易漏掉边界组合（例如 $M$ 极小、$K$ 极大这种不对称 shape，恰是索引计算与边界分支最易出错的地方）。工程上常用的做法是分层加边界强制：每个维度单独取最小、最大与对齐边界值做笛卡尔积的子集，再叠加随机抽样填充中间区域。其代价是样本数随维度数指数增长，必须用成对覆盖（pairwise covering）把组合数压到可接受范围。若题干要求「给出验证计划」，正确答法是写出覆盖准则与每类 shape 的样本配额，而不是笼统说「多测一些」。

另一个必须指出的机制是抽样与编译时间的耦合：每个新 shape 可能触发新的模板实例化或新的 tile 配置，编译时间不是常数。若候选 kernel 用模板对 shape 做特化，那么抽样越分散，编译次数越多，单样本成本越高；反之若候选 kernel 走动态 shape 路径，编译一次即可覆盖全部抽样，但运行时分支带来性能损失。这个 trade-off 是抽样题里少见的「正确性与性能同时受抽样策略影响」的点，值得在解题路径中单列一条。

六 · 解题路径的固化：从题干到可执行步骤

把上述拆解固化成一条可复用的路径，便于在考场或工程评审中逐条对照。第一步，变量表：标出随机变量（shape 元组及其各维度）、待估参数（分布 $p$ 的质量、$C(s)$ 的均值与方差）、决策变量（样本量 $n$、分层配额、候选间预算分配 $b_j$）。第二步，目标量：明确题干问的是期望、分位数还是候选间排序，三者对应的估计器与样本量公式不同。第三步，估计器选择：均匀抽样只在 $p$ 均匀时无偏，否则用重要性加权 $\hat{\mu}_w=\frac{1}{n}\sum \frac{p(s_i)}{q(s_i)}C(s_i)$（$q$ 为实际抽样分布），或直接分层。第四步，预算折算：用样本量下界乘单样本成本得到总预算，再与题干给的预算上限比较，若超限则说明精度要求不可达，需降级目标（例如从估 P99 降为估 P90）。第五步，验证覆盖：写出分层与边界强制的覆盖准则，并说明参考实现开销如何计入预算。

每一步都对应一个可检查的产出物：变量表、目标量表达式、估计器公式、预算不等式、覆盖准则。题干中任何一句模糊表述都应被归入这五者之一，而不是留作「大概理解」。例如「隐藏」一词若无法判定是估计误差还是分布偏移，就在第一步的变量表里把 $p$ 标为「未知但固定」与「随流量漂移」两种情形分别列出，后续公式自然分叉。这种写法在工程评审中比给出一个漂亮但假设不明的数字更有说服力。

最后落在具体机制上：该类题的所有公式最终都收敛到一个判断——当前抽样得到的估计量，其置信区间是否窄到足以区分「上线」与「不上线」两个动作。若区间跨越决策阈值，正确动作是增加样本或改变抽样分布（向决策敏感区域倾斜），而不是取点估计直接下结论。这一条机制把抽样、预算与上线判断串成闭环，也是本部分留给后续算例展开的接口。
